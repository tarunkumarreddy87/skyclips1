Removed the replaced renderer package, its deployment helpers and bridge, the obsolete CSS preview implementation, dead drawtext/ASS export code and their obsolete tests/proofs. Current editor controls and working UI are retained.

No byte-identical source duplicates were found; different-purpose code is retained. Original primary files are backed up outside the primary checkout under the current worktree cache.
